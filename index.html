Selamat Datang

Selamat datang di website SIPRAK 2.0 Ignatius Gavrilla Reda, mahasiswa S1 Sistem Informasi kelas PBI semester 3.

Website ini berisi informasi profil mahasiswa, jadwal kuliah, galeri foto, pendaftaran asisten, dan jurnal eksplorasi CSS.

Yang Berubah dari Tugas 2

Pada Tugas 3, tampilan website SIPRAK mulai menggunakan CSS eksternal melalui satu file css/style.css.

Tag frameset tidak lagi digunakan. Navigasi sekarang menjadi bagian dari setiap halaman sehingga setiap halaman dapat dibuka secara langsung.

Pengaturan tampilan yang sebelumnya menggunakan atribut HTML seperti bgcolor, border, dan align dipindahkan ke CSS.

Galeri Foto Kumpulan foto yang digunakan pada website SIPRAK.

Contoh Inline Style

Paragraf ini sengaja menggunakan inline style sebagai salah satu contoh untuk pembahasan pada jurnal.

Penggunaan inline style tidak menjadi cara utama dalam website ini karena pengaturan tampilan lainnya dilakukan melalui file CSS eksternal.
